# Nakout — Pick the model that wins

Pick the model that wins — tell us which AI plan you're on, and we'll match you with the best models for free/cheap, everyday, and heavy work, plus a test prompt for each.

A single-file static picker. Pick your provider → pick your plan → get model recommendations across three tiers (free/cheap, everyday, heavy), filterable by execution mode (plan, execute, review, research). Each pick includes a copy-pasteable test prompt.

## Supported providers
- **Command Code** (Go / GOAT / Pro / Max)
- **OpenAI** (Free, Plus, Pro, API)
- **Anthropic** (Free, Pro, Max, API)
- **Google** (Free, Advanced, Ultra, API)
- **xAI** (Free, SuperGrok, API)
- **OpenCode** (Zen / Go / BYO API key)
- **Local** (Ollama, vLLM)

## Usage
Open `nakout.html` in any modern browser. No build, no server, no dependencies.

## Notes
- Model ids & plan gates are best-effort and may be outdated as catalogs shift.
- Recommendations are friendly picks, not guarantees — always verify against the provider's current catalog.
- Personal reference tool — pull requests welcome but this isn't actively maintained.
